# Floating Custom Buttons

任意のWebページ上へ、自由に配置できるカスタムボタンを最大10個追加するManifest V3拡張です。ChromeとMicrosoft Edgeの両方で利用できます。

GitHub: <https://github.com/LightRoomJP/floating-custom-buttons>

## 主な機能

- HTTP/HTTPSのWebページ全般で利用可能
- Chrome/Edgeでローカルファイルへのアクセスを許可した場合は `file://` ページにも対応
- カスタムボタンを最大10個作成
- 表示中のタブのタイトルとURLからボタンを作成
- ドラッグによる自由配置
- 表示名、色、3段階のサイズを設定
- ボタン数・設定・位置を名前付きプリセットとして保存、読込、削除
- GitHub Releasesの新バージョン通知
- ChromeとMicrosoft Edge向けの個別配布zip
- ツールバー、拡張管理画面、通知で使用する専用アイコン

## インストール

- [Google Chromeへのインストール](docs/INSTALL_CHROME.md)
- [Microsoft Edgeへのインストール](docs/INSTALL_EDGE.md)

## 使い方

1. ブラウザのツールバーから拡張アイコンを開きます。
2. 「＋ 現在のタブから追加」、または「＋ 手動で追加」でボタンを作成します。
3. 表示名、動作、サイズ、色を選択し、「保存して反映」を押します。
4. 「配置を編集」を押して、ページ上のボタンをドラッグします。
5. ページ上部の「完了」、または設定画面の「配置編集を終了」を押します。

## 選べる動作

- ページを再読み込み
- 履歴を戻る
- 履歴を進む
- 現在のサイトのTOPへ移動
- 指定URLを現在のタブで開く
- 指定URLを新しいタブで開く

ChromeやEdgeの内部ページ、各ブラウザの拡張ストアなど、ブラウザがコンテンツスクリプトを禁止しているページにはボタンを表示できません。

## 配置プリセット

「配置プリセット」に名前を入力して「現在を保存」を押すと、ボタン数、動作、URL、色、サイズ、画面上の位置をまとめて保存できます。同じ名前で保存すると上書きします。プリセットを読み込んだ後の移動や編集は、保存済みプリセットを自動では書き換えません。

## アップデート通知

拡張機能は6時間ごととブラウザ起動時にGitHub Releasesを確認します。新しいReleaseがあると、デスクトップ通知、拡張アイコンの `UP` バッジ、設定画面で知らせます。

展開済み拡張はGitHubから自動差し替えできないため、通知からReleaseページを開き、ブラウザ別zipでファイルを更新してから拡張管理画面の「更新」を押してください。

更新確認では公開GitHub APIへ通常のHTTPリクエストを送ります。閲覧ページの内容、Cookie、入力内容は取得・送信しません。

## 権限とプライバシー

- `storage`: ボタン、配置、プリセット、更新状況の保存
- `alarms`: 6時間ごとの更新確認
- `notifications`: 新バージョンの通知
- `activeTab`: 拡張画面を開いたとき、表示中のタブをボタン化するため
- Webページへのアクセス: ページ上へボタンUIを表示するため
- `api.github.com`: 公開Releaseのバージョン確認のみ

この拡張はページの本文や入力内容を読み取りません。ユーザーがボタンを押したときだけ、設定されたブラウザ操作を実行します。

## Chrome / Edge互換性

ChromeとMicrosoft Edgeは同じChromium拡張APIを利用できるため、機能コードは共通です。Releaseでは導入手順を分けた2種類のzipを提供します。

アイコンの編集元は `icons/icon.svg` です。Pillowを導入したPython環境なら、マニフェストで使用するPNGを `python scripts/generate_icons.py` で再生成できます。

## リリース方法

`manifest.json` のバージョンを上げて `main` へpushすると、GitHub ActionsがChrome版とEdge版の配布zip、およびGitHub Releaseを自動作成します。同じバージョンのReleaseが存在する場合は再作成しません。
