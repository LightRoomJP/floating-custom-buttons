# グラブル Custom Buttons（Chrome拡張）

グラブルのページ上に、好きな位置へ置けるカスタムボタンを最大10個表示するManifest V3拡張です。元のElectronアプリは不要です。

GitHub: <https://github.com/LightRoomJP/granblue-custom-buttons>

## インストール

1. Chromeで `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. GitHub Releaseのzipを展開したフォルダ、またはこのリポジトリをcloneしたフォルダを選択します。
5. すでにグラブルを開いている場合は、そのタブを一度再読み込みします。

## 使い方

1. ツールバーの拡張アイコンを開き、「＋ ボタンを追加」からボタンを作ります。
2. 表示名、動作、サイズ、色を選び、「保存して反映」を押します。
3. 「配置を編集」を押し、グラブル画面上のボタンをドラッグします。
4. 画面上部の「完了」、または拡張画面の「配置編集を終了」を押します。

## 配置プリセット

「配置プリセット」に名前を入力して「現在を保存」を押すと、現在のボタン数、各ボタンの動作・色・サイズ、画面上の配置をまとめて保存できます。一覧から選んで「読込」を押すと、その構成へ切り替わります。同じ名前で保存すると既存プリセットを上書きします。

位置や設定は `chrome.storage.local` に保存されます。表示できるページは `https://game.granbluefantasy.jp/` のみに限定しています。

## アップデート通知

拡張機能は6時間ごととChrome起動時にGitHub Releasesを確認します。インストール中のバージョンより新しいReleaseがあると、Chrome通知、拡張アイコンの `UP` バッジ、設定画面の更新欄で知らせます。

Windows版ChromeはGitHubから展開済み拡張を自動差し替えできないため、通知からReleaseページを開き、次のどちらかで更新してください。

- Gitで導入した場合: `git pull` 後、`chrome://extensions/` の更新ボタンを押す
- zipで導入した場合: 新しいzipを展開して既存ファイルを置き換え、`chrome://extensions/` の更新ボタンを押す

更新確認では公開GitHub APIへリポジトリ名と通常のHTTP情報が送信されます。Cookieやゲームのデータは送信しません。

## 選べる動作

- 再読み込み
- 戻る
- 進む
- グラブルTOP (`#top`)
- 指定URLを現在のタブで開く

この拡張はクリックを自動化せず、ユーザーが押したときだけ通常のブラウザ操作を実行します。

## リリース方法

`manifest.json` のバージョンを上げて `main` へpushすると、GitHub Actionsが配布zipとGitHub Releaseを自動作成します。同じバージョンのReleaseがすでに存在する場合は再作成しません。
