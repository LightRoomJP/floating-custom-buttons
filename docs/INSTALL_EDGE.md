# Microsoft Edge インストールガイド

## 新規インストール

1. [GitHub Releases](https://github.com/LightRoomJP/floating-custom-buttons/releases/latest)を開きます。
2. Assetsから `floating-custom-buttons-edge-vX.X.X.zip` をダウンロードします。
3. zipを、削除や移動をしない任意のフォルダへ展開します。
4. Edgeのアドレスバーへ `edge://extensions/` と入力します。
5. 左側の「開発者モード」をオンにします。
6. 「展開して読み込み」を押します。
7. 展開先のうち、`manifest.json` が直接入っているフォルダを選択します。
8. すでに開いているWebページを再読み込みします。

必要に応じてEdgeの拡張メニューから「Floating Custom Buttons」をツールバーへ表示してください。

拡張画面の「＋ 現在のタブから追加」を押すと、そのタブのタイトルとURLが入力されたボタンを作成できます。追加後は「保存して反映」を押してください。

## ローカルHTMLで使用する場合

1. `edge://extensions/` でFloating Custom Buttonsの「詳細」を開きます。
2. 「ファイルのURLへのアクセスを許可する」をオンにします。
3. 対象のローカルHTMLを再読み込みします。

## 更新

1. 拡張から更新通知が届いたら、通知または「更新を見る」を押します。
2. 新しいEdge版zipをダウンロードします。
3. 既存の展開フォルダ内のファイルを新しい内容で置き換えます。
4. `edge://extensions/` の「更新」を押します。
5. ボタンを表示しているページを再読み込みします。

ボタン設定とプリセットはEdge内へ保存されるため、同じ拡張として更新する限り維持されます。念のため、展開フォルダそのものは削除せず、中のファイルを置き換えてください。

## 表示されない場合

- `edge://` ページやMicrosoft Edge Add-onsには表示できません。
- 通常のページを一度再読み込みしてください。
- 拡張のスイッチがオンになっているか確認してください。
- ローカルファイルでは「ファイルのURLへのアクセスを許可する」を確認してください。
